# Установка и откат Linux 7.2 на R36S-клоне (HiChip HC16E310)

> [!CAUTION]
> **СОВМЕСТИМОСТЬ — ТОЛЬКО HiChip HC16E310 (128 МБ ОЗУ)!**
> Этот порт проверялся **исключительно** на одной ревизии R36S-клона / семейства SF3000 на процессоре **HiChip HC16E310 (MIPS32 74Kf, 128 МБ RAM)** со стоковым загрузчиком `advapi32.dll` (`MD5: 3510ffdfd039f850345ace1489572659`).
> **НЕ устанавливайте** на Rockchip RK3326 (оригинальный R36S), Allwinner или платы GB350 с 256 МБ ОЗУ — консоль не загрузится.

---

## 1. Автоматическая установка в 1 команду (рекомендуется)

В релизный архив включён безопасный скрипт `install_to_sd.py`, который **сам проверяет MD5 стокового `advapi32.dll`** (`3510ffdfd039f850345ace1489572659`, блокирует несовместимые платы), делает двойной бэкап, раскладывает `cubegm/` + `neogeo.zip`/`pgm.zip` и сверяет SHA256 каждого файла:

```bash
# Этап A — безопасный 90-секундный пробный запуск (с авто-возвратом в сток):
python install_to_sd.py --sd E:\ --bundle r36s_linux72_hc16e310_v45_bundle.zip --mode trial --pc-backup C:\r36s_backup

# Этап B — постоянная установка (только после проверки Этапа A):
python install_to_sd.py --sd E:\ --bundle r36s_linux72_hc16e310_v45_bundle.zip --mode permanent

# Откат обратно на заводскую прошивку:
python install_to_sd.py --sd E:\ --mode rollback
```

---

## 2. Ручная проверка и резервная копия (если без скрипта)

1. Выключите консоль, вставьте microSD-карту в кардридер ПК.
2. Найдите файл `cubegm/advapi32.dll` на SD-карте.
3. Проверьте его MD5 (должен совпадать с `3510ffdfd039f850345ace1489572659`).
4. **Сохраните копию оригинального `advapi32.dll` на ПК и дополнительно как `cubegm/advapi32.dll.stock` на SD-карте.**

---

## 2. Копирование файлов рантайма на SD

Скопируйте содержимое папки `cubegm/` из релиза в `/cubegm/` на SD-карте:

- `driver_r36_combined.so` (единый DRM + ALSA драйвер видео/звука)
- `r36_hc16xx_drm.ko` (модуль дисплея DRM/KMS)
- `r36_hc16xx_i2s.ko` (модуль звука I2S)
- `r36-sysd` (демон яркости, громкости, GPIO15/19 PA, батареи и выключения)
- `r36-legacy-keys` + `evdev-to-legacy.map` (15-кнопочный мост ввода в `/tmp/joy_key`)
- `r36-tfkey` (утилита диагностики кнопок `r36-tfkey dump`)
- `fsck.fat` (автоматический ремонт FAT32 при грязном бите после внезапного отключения питания)
- `modules.tar.gz` (опциональные модули Wi-Fi/BT/USB)

### BIOS и совместимость эмуляторов

- **GBA:** `gba_bios.bin` должен лежать в `/cubegm/bios/` (или `/cubegm/lib/`). При выборе `gpsp_multicore_libretro.so` супервизор автоматически перенаправляет запуск на проверенное ядро `gpsp_libretro.so` (`942/942` GBA-игр PASS).
- **NeoGeo / PGM (аркады):** для запуска NeoGeo-игр через `fbalpha2012_neogeo_libretro.so` скопируйте `neogeo.zip` и `pgm.zip` из `/cubegm/cores/bios/` непосредственно в папку с аркадными ROM-ами (`/roms/MAME/` или `/MAME/`).
- **PlayStation 1 (PS1):** используйте libretro-ядро `pcsx_rearmed_libretro.so` (запускается автоматически через `picoarch_hi`, проверено `10/10` игр). Старый standalone `pcsx4all` не поддерживается без `/dev/fb0`.
- **Mega Drive:** если редкая игра (например `tribe.bin`) падает в `picodrive_libretro.so`, переключите ядро на `genesis_plus_gx_libretro.so`.

## 3. Безопасная двухэтапная установка

### Этап A — Безопасный 90-секундный пробный запуск (обязательно!)
1. Скопируйте оригинальный `advapi32.dll` в `cubegm/R36STOCK.ENC` (нужен для авто-восстановления).
2. Замените `cubegm/advapi32.dll` файлом `boot_images/trial_watchdog90/advapi32.dll`.
3. Вставьте SD-карту и включите консоль:
   - Консоль загрузит Linux 7.2, **до старта ядра автоматически восстановит стоковый `advapi32.dll` на SD** и даст 90 секунд для проверки меню TreeFrogUI, кнопок, яркости, звука и запуска игры.
   - Через 90 секунд аппаратный watchdog безопасно перезагрузит консоль обратно в сток.

### Этап B — Постоянная установка (только после успешного Этапа A)
1. Замените `cubegm/advapi32.dll` файлом `boot_images/permanent_release/advapi32.dll`.
2. Этот образ **не включает 90-секундный watchdog** и **не перезаписывает SD-карту при старте** (защита от повреждения FAT32 при потере питания).

---

## 4. Мгновенный откат на сток (1 шаг)

Если нужно вернуться на заводскую прошивку:
1. Выключите консоль и вставьте SD-карту в ПК.
2. Переименуйте/скопируйте сохранённый бэкап `advapi32.dll.stock` обратно в `cubegm/advapi32.dll`.
3. Вставьте карту обратно — консоль загрузится в заводскую прошивку.
